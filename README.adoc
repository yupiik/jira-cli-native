= Jira Cli

A simple JIRA cli using demonstrating the usage of Java 11, GraalVM and Apache OpenWebBeans (CDI container).

== Build

[source,sh]
----
mvn package -Pnative
----

== Usage

Pre-requisite: you built it, at that time there is no release yet or deliverable.

[source,sh]
----
# once for all
./target/jira-cli login \
    --jira-username "$USER\@company.com" \
    --jira-cloud-token 'xxxxxxx'

# then run a command
./target/jira-cli list \
    --jira-base https://.... \
    --jpql project=TEST
----

== Security

The `login` command persists your credentials as a Base64-encoded token in `~/.yupiikjiraclirc`.

Treat this file as a secret: make it readable only by its owner and never commit or share it.

[source,sh]
----
chmod 600 ~/.yupiikjiraclirc
----
